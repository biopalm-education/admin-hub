และห้องใหม่ได้ลิงก์ตามมาเป็นรอบ **รายสัปดาห์** (ผู้ใช้เลือก: เตือน 11:00 → ผู้ใช้เปิดแอป Claude → Claude เก็บ)
ผู้ใช้ **ไม่** ต้องการให้รันอัตโนมัติตอนกลางคืนบนเครื่อง

## รูปแบบลิงก์ (ตรวจแล้ว 22 ก.ย. ห้อง "กิตติประภา ภูมิซองแมว" เปิดถูกห้อง)
`https://business.facebook.com/latest/inbox/messenger?asset_id=691470034208676&business_id=310165158296126&mailbox_id=691470034208676&selected_item_id=<รหัสบัญชีจริงของลูกค้า>&thread_type=FB_MESSAGE`
- รหัสบัญชีจริง = `threadFBID` ใน React props ของแถวรายการแชท (ไม่ใช่ PSID และไม่ใช่ t_<id> จาก Graph API —
  ทดสอบแล้วทั้งสองแบบเปิดห้องล่าสุดแทน) · ลิงก์ `link` ของ Graph API ก็เปิดห้องล่าสุดแทน
- ใน Dashboard เก็บที่ `agg.fbuid` = {รหัสห้องแชท Graph (แถว[19]): รหัสบัญชีจริง} · ปัจจุบันมี 104 ห้อง
- ช่องค้นหาของ Business Suite ใช้หา id ไม่ได้ (ค้นได้แค่เนื้อความ)

## ท่อส่งข้อมูลที่พร้อมแล้ว (ทดสอบผ่าน 22 ก.ย.)
เบราว์เซอร์ในแอป Claude (business.facebook.com) → **form POST** ไป Apps Script v3 (`act:'links'`) → แท็บ "ลิงก์แชท FB"
ในชีต "Admin Hub · แชทที่ย้ายเอง" → workbench อ่านด้วย GET `?t=<token>&act=links` → `{links:[[id, ชื่อ, ts_ms], ...]}` (ค่าล่าสุดต่อ id)
- fetch/XHR จากหน้า Facebook ถูก CSP บล็อก ต้องใช้ form POST (ช่อง `p` = JSON) ผ่าน iframe ซ่อน — ใช้ได้
- URL /exec อยู่ใน `agg.ovurl` (ข้อมูลเข้ารหัส) · token = sha256('bp-ov|' + user:password จาก admin_secret.txt)
- ทดสอบแล้ว 5 ห้องอยู่ในชีต (by = "Claude (ทดสอบรอบแรก)")

## โค้ดเก็บรหัส (วางใน javascript_tool ที่แท็บ /latest/inbox/messenger) — ดู harvest.js
- **ห้ามพึ่ง localStorage** — Facebook ล้างคีย์แปลกปลอมทิ้ง (/ajax/webstorage/process_keys) ข้อมูล 666 ห้องหายไปแบบนี้
  ให้ส่งเข้าชีตทุก ~150–200 ห้องแทน
- ห้ามเขียน fiber walk แบบ recursive (เคยทำเบราว์เซอร์ค้าง) — ใช้ loop จำกัด 25 ชั้น
- แถวใน /latest/inbox/all มี IG ปนมาก ให้ใช้ /latest/inbox/messenger

## ปัญหาที่เจอวันนี้ (22 ก.ย.)
- เลื่อนรายการด้วย `scrollTop +=` ได้ ~670 ห้องแรก (ถึง ~4–6 ก.ย.) แล้ว **รายการหยุดโหลด** (spinner ค้าง)
  ทั้งแบบสคริปต์และแบบเลื่อนเมาส์จริง (computer scroll) — น่าจะโดน Facebook ชะลอหลังโหลดหนัก
- 2 ก.ย. วิธีเดียวกันเคยได้ 8,120 ห้องใน 25 นาที (scrollTop += 550 ทุก 250 ms) — แผนที่ชื่อ→id ชุดนั้นหายไปกับ sandbox
- แผน: ไปช้า ๆ (เลื่อนทีละ ~450px รอ 0.8–1.5 วิ) พักเป็นช่วง ถ้าค้าง >1 นาทีให้หยุดวันนั้น อย่าดันต่อ
  ถ้ารายการเริ่มต้นใหม่จากบนสุดทุกครั้ง ต้องเลื่อนผ่านช่วงที่เก็บแล้ว — ถ้าช้าเกินให้พิจารณาทำเป็นหลายวัน
