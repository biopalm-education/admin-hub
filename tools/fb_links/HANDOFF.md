## ท่อส่งข้อมูลที่พร้อมแล้ว (ทดสอบผ่าน 22 ก.ย.)
เบราว์เซอร์ในแอป Claude (business.facebook.com) → **form POST** ไป Apps Script v3 (`act:'links'`) → แท็บ "ลิงก์แชท FB"
ในชีต "Admin Hub · แชทที่ย้ายเอง" → workbench อ่านด้วย GET `?t=<token>&act=links` → `{links:[[id, ชื่อ, ts_ms], ...]}` (ค่าล่าสุดต่อ id)
- fetch/XHR จากหน้า Facebook ถูก CSP บล็อก ต้องใช้ form POST (ช่อง `p` = JSON) ผ่าน iframe ซ่อน — ใช้ได้
- URL /exec อยู่ใน `agg.ovurl` (ข้อมูลเข้ารหัส) · token = sha256('bp-ov|' + user:password จาก admin_secret.txt)
- ทดสอบแล้ว 5 ห้องอยู่ในชีต (by = "Claude (ทดสอบรอบแรก)")

## โค้ดเก็บรหัส (วางใน javascript_tool ที่แท็บ /latest/inbox/messenger) — ดู harvest.js

- แถวใน /latest/inbox/all มี IG ปนมาก ให้ใช้ /latest/inbox/messenger
