# tools — สคริปต์ดึงและแปลงแชท Facebook รายเดือน

ใช้ตอนเพิ่มข้อมูลเดือนใหม่ รันบน sandbox ที่มี token ของเพจ (ไม่มี credential ใด ๆ ในไฟล์เหล่านี้)

| ไฟล์ | หน้าที่ |
|---|---|
| `pull1` (ดูในบันทึก) | ไล่ `/{page}/conversations` ย้อนจากวันนี้จนถึงวันที่ 1 ของเดือนเป้าหมาย เก็บ 50 แชท/หน้า พร้อมข้อความล่าสุด 40 ข้อความ |
| `index.py` | ย่อไฟล์ดิบเป็น index.jsonl + เลือกแชทที่อาจมีข้อความในเดือนนั้น |
| `pull2.py` | ดึงข้อความเต็มของแชทที่เลือก (100 ข้อความ/หน้า + attachments) แล้วกรองเฉพาะช่วงเดือนนั้น (เวลาไทย) |
| `collect.py` | รวมไฟล์รายแชทเป็นไฟล์เดียว (อ่านแบบขนาน) |
| `build_june.py` | แปลงเป็น 2 ตารางของสเปรดชีต — สรุปรายแชท (20 คอลัมน์) และ ข้อความทั้งหมด (9 คอลัมน์) |
| `build_agg.py` | สร้าง `src/fb_YYYY-MM.json` สำหรับแดชบอร์ด + ตัวเลขสรุปของเดือน |

## เกณฑ์ที่ใช้ (ถอดจากเดือน ก.ค. 2026 แล้วทดสอบย้อนกับ 4,067 แชท)

- **ประเภทข้อความ** — ฝั่งเพจ: ขึ้นต้น `ตั้งระยะข้อมูลลูกค้าเป็น` = ระบบ Meta · ไม่มีตัวอักษร = สำเร็จรูป · ข้อความเดิมซ้ำ ≥5 ครั้งในเดือนและยาว >12 ตัวอักษร = สำเร็จรูป · นอกนั้น = แอดมินพิมพ์เอง
- **กลุ่ม** — S5: ป้าย Meta `สร้างคอนเวอร์ชั่นแล้ว` หรือข้อความสรุปยอด/เลขบัญชี · S0: ไม่มีข้อความลูกค้า · S4: ฝั่งเพจมีคำว่า `ค่าเรียน` · S3: มีคำว่า `บาท` · G: ลูกค้าพูดถึงของแถม · S2: ลูกค้าถามเรื่องคอร์ส · S1: นอกนั้น (ตรงกับ ก.ค. 98%)
- **ทีมที่ตอบ** — A = ข้อความที่คนพิมพ์เองมี `ครับ/คับ`, B = มี `ค่ะ/คะ`, AB = ทั้งคู่ (ตรงกับ ก.ค. 100%)
- **มาจากโฆษณา** — ในแชทมีข้อความ `BIOPALM ติวเตอร์วิชาชีวะ` (ตรง 100%)
- **ได้รับราคา** — ฝั่งเพจมี `บาท` หรือ `ค่าเรียน` (ตรง 99.8%)
- **ถามชั้นซ้ำ** — นับข้อความฝั่งเพจที่ถามระดับชั้น ≥2 ครั้ง (ตรง 99.2%)
- **เวลาตอบครั้งแรก** — จากข้อความแรกของลูกค้า ถึงข้อความแรกที่คนพิมพ์เองหลังจากนั้น
