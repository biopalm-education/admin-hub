# Before / After · ความคืบหน้าการเคลียร์แชท (preview v2 · 21 ต.ค. 2026)

หน้า preview: <https://biopalm-education.github.io/admin-hub/preview/> → ปุ่ม **Before / After** (แถบ “หน้า” ด้านบน) · ลิงก์ที่ลงท้าย `#ba` เปิดหน้านี้ทันที

## ดูอะไรได้
- กดปุ่ม Before / After → **ป๊อปอัปเลือกหมวด** ก่อน (ภาพรวมทุกหมวด หรือ 1 ใน 5 หมวด Follow up) พร้อมป้ายสถานะของแต่ละหมวด · เปลี่ยนหมวดได้จากปุ่ม “หมวด ▾”
- ช่วงเวลา: **รายสัปดาห์** (dropdown เลือกสัปดาห์) · **รายเดือน** (dropdown ตั้งแต่ ม.ค. 2026) · **กำหนดเอง** (ปฏิทิน เลือกวันแรก–วันสุดท้าย + ปุ่มลัด 7/14/30 วัน เดือนนี้ เดือนที่แล้ว ตั้งแต่ต้นปี)
- **การ์ดสถานะ** เทียบกับช่วงก่อนหน้าที่ยาวเท่ากัน: 🎉 ดีขึ้นชัดเจน · 👍 ดีขึ้น · ➖ ทรงตัว · 💪 ต้องเร่งอีกนิด + ประโยคให้กำลังใจ + สถิติดีที่สุดในรอบ (🏆 🏅 ⚡ 📉)
  - เคลียร์ได้ดีขึ้นไหม = แอดมินจัดการ (✅ + ✋) ÷ งานทั้งหมด · ต่าง ±5 จุดขึ้นไปจึงนับ
  - แชทค้างลดลงไหม = ค้างปลายช่วงเทียบค้างต้นช่วง
  - ตอบเร็วขึ้นไหม = แชทเข้าใหม่ แอดมินแตะ (พิมพ์ในแชทหรือกดปุ่ม) หลังเข้ารายการกี่วัน (ค่ากลาง) · ต่าง ±0.5 วันขึ้นไปจึงนับ
- **ก่อน → หลัง**: ค้างต้นช่วง (+ เข้าใหม่) → แอดมินจัดการ → ค้างปลายช่วง · แถบสีตามสถานะ
- ภาพรวมทุกหมวด: การ์ด 5 หมวด (ป้ายสถานะ + แท่งเล็ก % จัดการ 8 ช่วงล่าสุด) กดเพื่อเปิดหมวดนั้น
- **แนวโน้ม** 3 กราฟแยกกัน (% จัดการ · ค้างปลายช่วง · วันจนแตะแชทใหม่) ราย 12 สัปดาห์ หรือรายเดือนตั้งแต่ ม.ค. · กดแท่งเพื่อเปิดช่วงนั้น
- **Source**: ปุ่ม “ดูรายชื่อแชท” หรือกดตัวเลข → รายชื่อแชท กรองสถานะ/ช่องทาง ค้นชื่อ เปิดแชท ดาวน์โหลด CSV
- ตัวอย่างข้อความแจ้งเตือนเข้า LINE กลุ่ม (ปุ่มคัดลอก)
- หน้า **Follow up** (แต่ละช่องทาง): การ์ด “ความคืบหน้าหมวดนี้ · สัปดาห์นี้” แทนตารางรายสัปดาห์เดิม + ปุ่มไปดูละเอียด · ถ้ายังไม่มี ba.json จะแสดงตารางเดิม

## ข้อมูล
`build_week.py` (รันทุกเช้าในรอบอัปเดต) เขียน `src/ba.json` → `build.py` เข้ารหัสเป็น `data/ba.json` (โหลดเฉพาะหน้านี้และการ์ดในหน้า Follow up)
- ไทม์ไลน์รายวันของทุกแชทในแต่ละหมวด ตั้งแต่ 1 ม.ค. 2026 (ตัดเที่ยงคืน กฎเดียวกับรายการ Follow up) + วันที่แอดมินพิมพ์ + ปุ่มที่กด → หน้าเว็บนับช่วงไหนก็ได้
- ตรวจแล้ว (ข้อมูลจำลอง): ทุกสัปดาห์ ทุกหมวด ทุกช่องทาง ตรงกับ `wk.sum` 135/135 ทั้งใน Python และในหน้าเว็บ · `followup.json` คีย์ `wk` เหมือนเดิม
- 🎬 🗨️ 💸 เริ่มนับ 19 ส.ค. 2026 ตามกติกาทีม (เดือนก่อนหน้าแสดงว่าไม่มีข้อมูล ไม่ใช่ 0) · 🤖 🧾 นับตั้งแต่ ม.ค.
- ข้อมูลจำลองขนาดใหญ่: build_week ~45 วินาที · ba.json ~2 MB (บีบอัดแล้ว ~0.4 MB) · เปิดหน้า ~0.5 วินาที เปลี่ยนช่วง < 0.25 วินาที
- ก่อนรอบอัปเดตแรกที่สร้าง ba.json: หน้า Before / After ขึ้นข้อความรอ · หน้า Follow up ใช้ตารางเดิม
