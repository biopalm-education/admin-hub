# Before / After · แอดมินเคลียร์แชทได้เท่าไร (preview 20 ต.ค. 2026)

หน้า preview: <https://biopalm-education.github.io/admin-hub/preview/> → ปุ่ม **Before / After** (แถบ “หน้า” ด้านบน) · ลิงก์ที่ลงท้าย `#ba` เปิดหน้านี้ทันที

## ดูอะไรได้
- **ทุกช่องทาง** หรือเจาะ Facebook / Instagram / LINE OA (ปุ่มช่องทางด้านบนเดิม)
- **รายสัปดาห์** (จันทร์–อาทิตย์) หรือ **รายเดือน** (วันที่ 1 → สิ้นเดือน) · เลือกสัปดาห์/เดือนได้
- **ก่อน → หลัง**: ค้างต้นช่วง (+ เข้าใหม่) → แอดมินจัดการ (✅ เคลียร์แล้ว · ✋ ตอบ/ตามแล้ว) → ค้างปลายช่วง (▲▼)
- อ่านผลอัตโนมัติ · ตารางแยก 5 หมวด Follow up · ตารางหมวด × ช่องทาง · ย้อนหลังทุกสัปดาห์/เดือน (จุดอ่อน = ต้นช่วง จุดเข้ม = ปลายช่วง)
- **Source**: กดชื่อหมวดหรือตัวเลขไหนก็ได้ → รายชื่อแชทเบื้องหลังตัวเลขนั้น กรองหมวด/ช่องทาง/สถานะ ค้นชื่อ เปิดแชทได้ ดาวน์โหลด CSV
- กรองอายุแชท (ทั้งหมด · ไม่เกิน 29 วัน · 30 วันขึ้นไป) เพื่อแยกกองเก่าออกจากงานใหม่
- ตัวอย่างข้อความแจ้งเตือนเข้า LINE กลุ่ม ของช่วงที่เลือก (ปุ่มคัดลอก)

## ข้อมูล
ใช้ `followup.json` คีย์ `wk` จาก `build_week.py` (รันทุกเช้าในรอบอัปเดต) — ตัวเลขชุดเดียวกับกล่องรายสัปดาห์ในหน้า Follow up
- v2 (20 ต.ค. 2026) เพิ่ม `months / mrows / msum` (รายเดือน ตั้งแต่ ก.ย. 2026 เก็บ 4 เดือนล่าสุด) และ `row[6]` = อายุแชทตอนเข้ารายการ
- รายสัปดาห์เหมือนเดิมทุกตัว (ทดสอบกับข้อมูลจำลอง: rows/sum ตรงกับ v1 ทุกแถว · ค้างปลายสัปดาห์ = ค้างต้นสัปดาห์ถัดไป ทุกหมวดทุกช่องทาง ทั้งรายสัปดาห์และรายเดือน · ตัวเลขในหน้า = sum ใน build_week 165/165)
- ก่อนรอบอัปเดตแรกหลังเพิ่ม v2: แท็บรายเดือนขึ้นข้อความรอ · ตัวกรองอายุซ่อนไว้

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `ba.js`, `ba.css` | หน้า Before / After (ใช้ฟังก์ชันนับของ `tools/followup_week/wk.js`) |
| `patch_ba.py` | ใส่หน้า Before / After ลงไฟล์ที่ผ่าน `tools/followup_week/patch_app.py` แล้ว · ทุกจุดต้องเจอครั้งเดียว ไม่งั้นไม่เขียนไฟล์ |

สร้างหน้า preview ใหม่ (เมื่อแก้ `app.html` หรือไฟล์ในสองโฟลเดอร์นี้): `python3 tools/followup_week/patch_app.py app.html /tmp/p1.html && python3 tools/before_after/patch_ba.py /tmp/p1.html preview/index.html`

ขึ้นหน้าจริงเมื่ออนุมัติ: `python3 tools/followup_week/patch_app.py app.html /tmp/p1.html && python3 tools/before_after/patch_ba.py /tmp/p1.html app.html` แล้ว deploy ตามปกติ
