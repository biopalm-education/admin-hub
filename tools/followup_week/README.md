## ทำอะไร
- `build_week.py` (root) อ่านแชททุกห้องย้อนหลัง **ทีละวัน (เที่ยงคืน)** 8 สัปดาห์ + สัปดาห์นี้ ด้วยกฎเดียวกับรายการ Follow up ทั้ง 5 หมวด
  (`build_fu.py` = บอทตอบ · `build_pay.py` = ยังไม่แนบตัวอย่าง / ยังไม่สรุปจ่าย / ยังไม่โอน 2 หมวด)
  แล้วเขียน `src/followup.json` คีย์ `wk` — ต่อแชทต่อสัปดาห์: อยู่ในรายการต้นสัปดาห์ไหม · เข้าใหม่ไหม · ปลายสัปดาห์ไปอยู่ไหน · มีแอดมิน (คน) พิมพ์ในแชทระหว่างนั้นไหม
- รวมปุ่มที่กดในหน้าเว็บ (✓ ตอบแล้ว / ✓ ตามแล้ว / ไม่ต้องตาม จากชีทส่วนกลาง) ตามเวลาที่กด
- เขียนข้อความรายงานรายสัปดาห์ (`wk.report.msgs` = 1 ข้อความต่อช่องทาง) ไว้ส่งเข้า LINE กลุ่ม
- รันอัตโนมัติทุกเช้าใน `tools/auto/refresh.py` ต่อจาก `build_stage.py` (พลาดแล้วไม่หยุดรอบอัปเดต) · log พิมพ์แต่ตัวเลข
  และเช็กเองว่า "แชทในรายการวันนี้" ตรงกับรายการที่หน้าเว็บโชว์ (`now x/page y` ต้องเท่ากัน)

## นับอย่างไร (ต่อหมวด ต่อสัปดาห์ จันทร์–อาทิตย์)
| ช่อง | ความหมาย |
|---|---|
| ค้างต้นสัปดาห์ | อยู่ในรายการตอนเที่ยงคืนวันจันทร์ |
| เข้าใหม่ | เข้ารายการระหว่างสัปดาห์ |
| ✅ เคลียร์แล้ว | ขยับขั้น/จบ — บอทตอบ: แอดมินตอบ · ยังไม่แนบตัวอย่าง: ส่งตัวอย่าง/สรุปยอด · ยังไม่สรุปจ่าย: ส่งสรุปยอด · ยังไม่โอน: โอนแล้ว (ทุกหมวด: โอนแล้วนับด้วย) |
| ✋ ตอบ/ตามแล้ว | แอดมินพิมพ์ในแชทระหว่างที่อยู่ในรายการ (ทักตาม · ตอบคำถามใหม่ · สรุปยอดรอบใหม่) แต่ยังอยู่ขั้นเดิม · หรือกดปุ่มในหน้าเว็บ |
| 💬 ลูกค้าทักกลับ รอตอบ | ลูกค้าส่งข้อความใหม่ ยังไม่มีแอดมินตอบ — **ไม่นับเป็นเคลียร์** |
| ⏳ ยังไม่มีใครแตะ | อยู่ในรายการถึงปลายสัปดาห์ ไม่มีแอดมินพิมพ์เลย |
| ระบบคัดออก · หมดอายุ | ลูกค้าปฏิเสธ/นักเรียนเดิม/ไปคุย LINE (ระบบคัดเอง) · เกิน 90 วัน — ไม่นับในตัวหาร |
| ค้างปลายสัปดาห์ | อยู่ในรายการตอนจบสัปดาห์ (ไม่นับแชทที่กดย้ายเอง) |
| แอดมินจัดการ | (เคลียร์ + ตอบ/ตาม) ÷ (ค้างต้น + เข้าใหม่ − ระบบคัดออก − หมดอายุ) |

แอดมิน = คนกดส่ง (Facebook: ป้าย source ของ Meta · Instagram: เทียบข้อความเดียวกันบน Facebook · LINE: ชื่อผู้ส่งที่ LINE บอก)
ชื่อแอดมินรายคน: LINE มีทุกข้อความ · Facebook/Instagram มีเฉพาะชื่อที่เลือกตอนกดปุ่มในหน้าเว็บ

## แก้ของเดิมที่นับผิด (กล่อง "แชทค้างไปไหน")
- หมวดตัวอย่าง/สรุปจ่าย: ลูกค้าถามต่อแล้วแอดมินตอบใน 24 ชม. → เคยขึ้น "หลุดเพราะเกิน 90 วัน" · ตอบเมื่อ 2–6 วันก่อน → เคยขึ้น "ยังไม่มีใครตาม"
- ลูกค้าถามต่อแต่ยังไม่มีใครตอบ → เคยนับเป็น "เคลียร์ได้"
- หมวดบอทตอบ: ลูกค้าทักซ้ำภายใน 7 วัน → เคยนับเป็น "กลายเป็นไม่ต้องตาม" (เคลียร์ได้)
