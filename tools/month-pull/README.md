# ดึงข้อมูลแชท Facebook เพิ่มทีละเดือน

สคริปต์ชุดนี้คือของจริงที่ใช้ดึงเดือน มี.ค. 2026 เก็บไว้ที่นี่เพราะพื้นที่ทำงานชั่วคราวของ Composio
เคยถูกล้างมาแล้วครั้งหนึ่ง (2 ก.ย. 2026) ทำให้ต้องเขียนใหม่ทั้งชุด

## ลำดับการทำงาน (แก้วันที่ในไฟล์ก่อนรัน)

1. `walk_lean.py` — ไล่รายชื่อบทสนทนาของเพจย้อนหลังจนถึงวันที่ 1 ของเดือนเป้าหมาย
   เก็บแค่ `id,updated_time,message_count` ต่อหน้าละ 100 รายการ **เร็วกว่าแบบเต็มมาก**
   (`walk_full.py` เป็นแบบเดิมที่ขอ `messages.limit(40)` มาด้วย — ช้ากว่า 5-10 เท่า
   แต่ช่วยคัดผู้สมัครออกได้เยอะกว่า ใช้เมื่อไม่อยากให้ขั้นตอนที่ 3 หนัก)
2. `index_candidates.py` — รวมหน้าที่ไล่มาทั้งหมด คัดเฉพาะแชทที่อาจมีข้อความในเดือนเป้าหมาย
3. `fetch_messages.py` — ดึงข้อความเต็มของแชทที่คัดไว้ แล้วกรองเหลือเฉพาะเดือนนั้น (เวลาไทย)
4. `build_columns.py` — คำนวณทุกคอลัมน์ของชีต (กลุ่ม S0–S5, ทีม A/B, เวลาตอบ ฯลฯ)
   ใช้เกณฑ์เดียวกันทุกเดือน ห้ามแก้ ไม่งั้นตัวเลขข้ามเดือนจะเทียบกันไม่ได้
5. `push_to_sheet.py` — เขียนลง Google Sheets ทีละ 1,000 แถว มี checkpoint กันงานหลุด
6. `decrypt.py` + `build_dashboard_month.py` + `../../build.py` — ถอดรหัสข้อมูลที่ deploy อยู่
   กลับมาเป็น src/ เพิ่มเดือนใหม่ แล้ว build + push ขึ้น GitHub Pages

## ข้อควรจำ

- โทเคนเพจ Facebook ออกใหม่ได้เสมอจาก Composio `FACEBOOK_GET_USER_PAGES`
  → `data.data[0].access_token` (เพจ BioPalm 691470034208676)
- `secret.txt` และ `gh_token.txt` เก็บสำรองไว้ในโฟลเดอร์ Drive
  "Biopalm Chat Dashboard - Backup 2026-09-01"
- ก่อน push ทุกครั้งให้ clone repo ใหม่แล้วถอดรหัสจากของที่ deploy อยู่จริง
  เพราะอาจมีงานอื่น (เช่น Instagram / LINE) push เข้ามาระหว่างทาง
- อย่าเก็บไฟล์ผลลัพธ์ไว้บน /mnt/files อย่างเดียว — เขียนลง /tmp แล้ว copy เป็น .tgz
  (เขียนไฟล์ใหญ่ลง /mnt/files ตรง ๆ จะ error ตอนปิดไฟล์)
